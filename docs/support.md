# Support

When reporting an integration issue, include:

- SDK version and source commit from the Compatibility Record;
- Android/iOS version and device model;
- scanner model, hardware, main firmware, and Bluetooth firmware;
- transport, operation, SDK error code, and sanitized reproduction steps;
- whether the session remained usable after the failure.

Do not include scan plaintext, raw hex, full device IDs, serial numbers,
credentials, or customer data.

Public issues:

- https://github.com/netumscan/scanner-sdk-android/issues
- https://github.com/netumscan/scanner-sdk-ios/issues
- https://github.com/netumscan/scanner-sdk-samples/issues
