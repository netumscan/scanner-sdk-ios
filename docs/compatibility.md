# Mobile Compatibility

## Supported SDK Scope

- Android 8.0+ (`minSdk 26`), BLE GATT.
- iOS 15+, BLE GATT.
- macOS 12+, BLE GATT.
- Android SPP Classic is a compatibility skeleton and is not part of the
  mobile 1.0 support commitment.
- Mobile USB HID is outside the 1.0 support scope.

Compatibility evidence is specific to the recorded phone, operating system,
scanner model, hardware, main firmware, Bluetooth firmware, transport, SDK
version, and SDK commit. A result for one firmware combination must not be
generalized to all devices with the same marketing model.
